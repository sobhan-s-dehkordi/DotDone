# DotDone | دات‌دان

نرم‌افزار مدرن و شخصی مدیریت تسک‌ها و پروژه‌ها با معماری سلسله‌مراتبی، گراف فعالیت الهام‌گرفته از گیت (Heatmap)، سیستم استریک پیوسته مشابه دولینگو، پشتیبانی دوزبانه و فونت وزیرمتن.

---

## 🚀 ویژگی‌های کلیدی (Key Features)

1. **ساختار سلسله‌مراتبی منظم (Hierarchy):**
   * **مخزن (Repository):** حوزه اصلی (مثلاً شخصی، کاری، یادگیری).
   * **پروژه (Project):** پروژه‌های ذیل هر مخزن.
   * **تسک اصلی (HeadTask):** وظایف اصلی هر پروژه.
   * **زیرتسک (SubTask):** گام‌های اجرایی هر تسک اصلی.

2. **اطلاعات جامع آیتم‌ها:**
   * **عنوان:** اجباری
   * **توضیحات:** اختیاری (حداکثر ۵۰۰ کاراکتر با شمارنده آنلاین)
   * **وضعیت:** انجام نشده (`Todo`) / درحال انجام (`InProgress`) / انجام شده (`Done`)
   * **توضیحات تکمیلی:** اختیاری (حداکثر ۵۰۰ کاراکتر، جهت یادداشت بعد از بررسی و انجام)
   * **ضمائم (Attachments):** پیوست فایل و ذخیره‌سازی محلی و ایزوله در کنار برنامه
   * **تاریخ‌ها:** ثبت سیستمی تاریخ ایجاد و تغییر با پشتیبانی تقویم شمسی و اعداد فارسی

3. **گراف فعالیت (Git-style Heatmap):**
   * نمایش ماتریس فعالیت سالانه با ۵۲ ستون در ۷ ردیف.
   * **معیار فعالیت:** فقط تغییر وضعیت به **«درحال انجام» (ضریب ۱)** و **«انجام شده» (ضریب ۲)** امتیاز فعالیت دارند.
   * فیلتر سریع بین **«همه مخازن»** یا **«پروژه جاری»**.
   * تاریخچه گراف ماندگار است و هرگز صفر نمی‌شود.

4. **سیستم استریک دولینگو و ریکاوری غیبت (Streak System):**
   * قابلیت فعال‌سازی برای هر مخزن به دلخواه.
   * در صورت بی‌فعالیتی شکسته می‌شود، اما **دیالوگ ریکاوری هوشمند** قبل از صفر شدن به شما امکان می‌دهد در صورت فعالیت آفلاین، تسک‌های انجام‌شده را با تاریخ مشخص تیک بزنید تا استریک حفظ شود.

5. **شبیه‌سازی و جابجایی تسک‌ها (Task Transfer):**
   * **کپی عمیق:** تکثیر کامل یک تسک اصلی به همراه تمام زیرتسک‌ها و فایل‌های پیوست به پروژه‌ای دیگر.
   * **انتقال:** جابجایی سریع تسک به پروژه دیگر بدون تکرار دیتای دستی.

6. **رابط کاربری مدرن با WinUI 3:**
   * طراحی مینیمال و آرام؛ فقط اطلاعات مهم نمایش داده می‌شود و جزئیات کامل با **دبل کلیک** باز می‌شود.
   * تایپوگرافی زیبا با فونت **وزیرمتن (Vazirmatn)**.
   * پشتیبانی کامل دوزبانه (فارسی RTL و انگلیسی LTR) و اعداد بومی.
   * سوییچ سریع تم ویندوز (روشن / تاریک).
   * برنامه به صورت **Unpackaged** پیکربندی شده تا دیتابیس SQLite و فایل‌های پیوست در پوشه `DotDone_Data` کنار فایل اجرایی ذخیره شوند.

## 📂 ساختار سورس‌کد (Architecture)

```text
DotDone/
├── src/
│   ├── DotDone.Core/           # مدل‌های دامین، انتیتی‌ها و اینام‌ها (.NET 10)
│   ├── DotDone.Data/           # کانکشن دیتابیس SQLite، نگاشت EF Core و سرویس فایل
│   ├── DotDone.Services/       # منطق استریک، گراف فعالیت، انتقال تسک و بومی‌سازی
│   └── DotDone.UI/             # پروژه دسکتاپ WinUI 3 (Controls, Dialogs, ViewModels)
└── tests/
    └── DotDone.Tests/          # تست‌های واحد خودکار با xUnit و FluentAssertions
```

## 🧪 اجرای تست‌های خودکار

برای اجرای تمام تست‌های اعتبارسنجی لاجیک استریک، گراف، جابجایی و مدل داده:
```bash
dotnet test tests/DotDone.Tests/DotDone.Tests.csproj
```

## 💻 نحوه اجرای برنامه

```bash
dotnet run --project src/DotDone.UI/DotDone.UI.csproj -r win-x64
```
یا اجرای مستقیم فایل باینری تولید شده:
```text
src/DotDone.UI/bin/Debug/net10.0-windows10.0.26100.0/win-x64/DotDone.UI.exe
```
